CONSOLE ACCESS

GO FULLSCREEN

This handheld console requires Landscape Fullscreen mode for proper display and controls.

Console controls

Use Up and Down to highlight menu items or scroll a page. Press the right D-pad button, left joystick, or Enter to select. The left D-pad button goes back. Home or Escape returns to Home. The square button (or M key) mutes/unmutes audio. The right-hand buttons are reserved for socials.
