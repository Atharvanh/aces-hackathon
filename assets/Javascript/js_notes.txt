//generating random whole numbers within a particular range
function random_whole(min,max) {
    return Math.floor(Math.random() *(max-min+1) + min);
}
console.log(random_whole(1,100));

let keyword doesnt allows you to use the same var_name twice (throws error);
while var when used twice with the same var_name it returns the last value of the variable
(therefore using let is considered better than using var)

scope of the var and let keywords
let keyword is only valid in the block in which it is declared
var keyword is valid in the entire function block in which it is declared
use const keyword when we you want a variable which doesnt changes it value at any case
(most of the times use either let or const minimize the use of var as much possible)

mutate an array declared with const
you cant directly change an array when it is declared by using the const keyword
but you can change the element of array by indexing

prevent object mutation
as an object or an array can still be mutated even after using the keyword const 
to prevent an object from mutation use object.freeze(name_of_the_object_to_be_protected);
